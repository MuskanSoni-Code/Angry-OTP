# 🎯 OTP Slingshot Verification Game

An interactive and engaging **OTP Verification Game** built with **React.js** and **Tailwind CSS**.

Instead of entering an OTP normally, users select digits and use a **slingshot interaction** to hit the correct OTP slots and complete the 6-digit verification code.

## ✨ Features

* 🎯 Interactive slingshot-based OTP verification
* 🔢 6-digit OTP slot system
* 🏹 Drag and release interaction
* 🎨 Clean and responsive user interface
* ⚡ Built with React.js
* 💨 Styled using Tailwind CSS
* 🪟 OTP verification popup
* 🔄 Reset functionality after verification
* 📱 Responsive design

## 🛠️ Technologies Used

* **React.js**
* **JavaScript**
* **Tailwind CSS**
* **Vite**
* **HTML5**

## 🎮 How It Works

1. Select an OTP digit.
2. Pull the slingshot by dragging it.
3. Release the slingshot to launch the digit.
4. The selected digit is added to the OTP slot.
5. Repeat the process until all 6 digits are filled.
6. Complete the OTP verification.

## 🚀 Getting Started

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Go to the project folder:

```bash
cd OTP-Slingshot
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.

## 🎯 Project Goal

The main goal of this project is to experiment with **React state management, pointer events, drag interactions, and interactive UI design** while creating a fun alternative to traditional OTP verification.
